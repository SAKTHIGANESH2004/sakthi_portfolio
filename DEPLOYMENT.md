# 🚀 Deployment Guide: Sakthiganesh K Data Analyst Portfolio

This repository (`https://github.com/SAKTHIGANESH2004/sakthi_portfolio`) is pre-configured for instant 1-click deployment on **Netlify**, **Vercel**, and **Render**, with direct recruiter inquiry forwarding to **`sakthiganeshk27@gmail.com`**.

---

## 🌐 Option 1: Deploy to Netlify (Recommended)

### Step 1: Connect your GitHub Repository on Netlify
1. Go to **[Netlify.com](https://app.netlify.com)** and log in with your GitHub account (`SAKTHIGANESH2004`).
2. Click **"Add new site"** -> **"Import an existing project"**.
3. Select **GitHub** and choose the repository: **`SAKTHIGANESH2004/sakthi_portfolio`**.

### Step 2: Automatic Build Settings (Pre-configured via `netlify.toml`)
Netlify will automatically detect the settings from `netlify.toml`:
- **Base directory**: `client`
- **Build command**: `npm run build`
- **Publish directory**: `client/dist` (or `dist`)

### Step 3: Click "Deploy Site"
- Netlify will build your site in ~30 seconds.
- You will receive a live URL like: `https://sakthiganesh-portfolio.netlify.app`!
- You can also change the site name to your own custom domain (e.g. `sakthiganesh-analytics.netlify.app` or `sakthiganesh.me`).

---

## 🌐 Option 2: Deploy to Vercel (Alternative)

1. Go to [Vercel.com](https://vercel.com) and log in with GitHub.
2. Click **"Add New Project"** and select **`sakthi_portfolio`**.
3. The pre-configured `vercel.json` will automatically build the project.
4. Click **"Deploy"**!
