# 🚀 Sakthiganesh K — Interactive Data Analyst Portfolio (MERN Stack)

A modern, high-performance interactive Data Analyst portfolio built with **Node.js/Express, React, Tailwind CSS, Recharts, and MongoDB**. Spotlights real-world analytics achievements, 780,000+ job postings EDA, SQL cohort/churn modeling, IoT anomaly detection, and hierarchical energy forecasting.

---

## 🌟 Interactive Flagship Features

1. **U.S. Data Job Market Explorer (780K+ Postings EDA)**
   - *Interactive Recharts Visualizer*: Toggle between Skill Demand %, Top Paying Skills ($), Role Salary Ranges, and Salary Distribution density.
   - *GitHub Repo*: [`python-data-analyst-market-analysis`](https://github.com/SAKTHIGANESH2004/python-data-analyst-market-analysis)

2. **Interactive SQL Studio (Live Query Runner)**
   - *PostgreSQL Simulator*: Run CTEs, Window Functions (`DENSE_RANK()`), and aggregations.
   - Live query plan execution timer & responsive data table rendering with copy support.
   - *GitHub Repos*: [`data-analyst-salary-skills-sql`](https://github.com/SAKTHIGANESH2004/data-analyst-salary-skills-sql) & [`sql-cohort-churn-ltv-analysis`](https://github.com/SAKTHIGANESH2004/sql-cohort-churn-ltv-analysis)

3. **Cohort Retention Heatmap & What-If Churn Simulator**
   - 12-month customer retention decay matrix with intensity cell formatting.
   - Real-time What-If LTV & Churn sliders to model CAC payback and lifetime value.

4. **Hierarchical Energy Demand Predictive Forecast**
   - 30,000+ hours telemetry model comparison (ARIMA/SARIMA vs XGBoost vs Actuals) demonstrating a **36.2% RMSE reduction** (1.91% MAPE) and ~$50,000 annual savings.

5. **STAR Case Studies & Deep-Dive Modals**
   - Structured Situation, Task, Action, Result breakdowns for all projects with architecture flowcharts and key strategic insights.

6. **Interactive Resume & Lead Dispatch**
   - Printable in-browser verified resume viewer.
   - Full-stack contact form persisting inquiries to Express / MongoDB backend with instant validation and confetti celebrations.

---

## 🛠️ Architecture & Tech Stack

- **Frontend**: React 18/19, Vite, Tailwind CSS, Recharts, Lucide Icons, Canvas-Confetti
- **Backend**: Node.js, Express REST API, CORS, MongoDB & Mongoose (with seamless in-memory fallback store)
- **Data Analytics Tools**: Python (Pandas, NumPy, Matplotlib, Seaborn), SQL (PostgreSQL), Power BI, Snowflake, AWS, GCP BigQuery, DBT, Airflow

---

## 🚀 Quick Start Guide

### 1. Run Backend Server (Port 5000)
```bash
cd server
npm start
```

### 2. Run Frontend Client (Port 3000)
```bash
cd client
npm run dev
```

Open `http://localhost:3000` in your browser to interact with the full live portfolio!
